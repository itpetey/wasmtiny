# Audited unsafe-code allowlist for wasmtiny (src/ only).
#
# Format: <repo-relative-path> <allowed-count> <reason>
# The CI check (scripts/check_unsafe.sh) counts unsafe-code items per
# file (unsafe blocks, unsafe fn, unsafe impl) and compares against
# this list. Any off-list occurrence, any count drift, or any file
# missing here fails the gate.
#
# Guests (tests/corpus) are EXEMPT by design: they are hostile
# binaries/fixtures, not wasmtiny code. No static gate applies to
# guest payloads (docs/threat-model.md).

src/runtime/shared_memory.rs 12 shm_open/mmap/ftruncate for shared regions and raw mapping teardown; every site carries a SAFETY comment
